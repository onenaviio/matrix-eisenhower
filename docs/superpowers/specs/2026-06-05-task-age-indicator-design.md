# Индикатор времени ожидания задач в срочных квадрантах

Дата: 2026-06-05

## Цель

Показывать на карточках задач в **срочной колонке** матрицы Эйзенхауэра
цветовой индикатор того, как давно задача создана и «висит» невыполненной.
Это помогает замечать застрявшие срочные задачи.

## Область

Индикатор отображается на задачах двух срочных квадрантов:

- `do` — СДЕЛАТЬ (срочно + важно)
- `delegate` — ДЕЛЕГИРОВАТЬ (срочно + неважно)

Несрочные квадранты (`plan`, `delete`) индикатора не показывают.

## Данные

Изменений в модели данных **не требуется**. Поле `Task.createdAt: number`
(unix-миллисекунды) уже пишется в `makeTask` при создании задачи. Существующие
задачи получат индикатор автоматически по их реальному времени создания.

Возраст задачи = `now − createdAt`.

## Визуальный индикатор

Небольшой цветной кружок в карточке задачи (слева, перед текстом).
Цвет определяется возрастом:

| Возраст            | Уровень | Цвет     |
|--------------------|---------|----------|
| менее 3 часов      | fresh   | зелёный  |
| от 3 до 8 часов    | warning | жёлтый   |
| более 8 часов      | stale   | красный  |

Границы: `[0, 3ч)` → зелёный; `[3ч, 8ч)` → жёлтый; `[8ч, ∞)` → красный.

## Тултип

Кастомный CSS-тултип (не нативный `title`), появляется при наведении на
кружок. Текст — относительная длительность ожидания на русском:

- «висит 5 ч 12 мин»
- «висит 42 мин» (если меньше часа)
- «висит 1 ч 03 мин»

Округление до минут. Правильные русские формы единиц («ч», «мин» —
несклоняемые сокращения, без падежных проблем).

## Живое обновление

Возраст растёт со временем, поэтому цвет и текст должны обновляться без
перезагрузки страницы:

- В компоненте `EisenhowerMatrix` — реактивное поле `now: number`.
- `setInterval` обновляет `now` раз в 60 секунд.
- Интервал создаётся в `created`/`mounted`, очищается в `beforeUnmount`.
- Возраст, уровень и подпись пересчитываются как методы от `now` и
  `task.createdAt` (реактивность через зависимость от `now`).

## Структура кода

### Новый модуль: `src/storage/taskAge.ts`

Чистые функции, без зависимости от Vue (в духе `ordering.ts` / `taskStorage.ts`):

- `taskAge(createdAt: number, now: number): number` — возраст в миллисекундах.
- `ageLevel(ageMs: number): 'fresh' | 'warning' | 'stale'` — уровень по порогам
  (пороги-константы: 3ч и 8ч в мс).
- `formatDuration(ageMs: number): string` — «5 ч 12 мин» / «42 мин».

Функции написаны как чистые и тестируемые, но тест-раннер сейчас не ставится
(в проекте его нет; см. раздел «Тестирование»).

### Компонент: `src/components/EisenhowerMatrix.vue`

- `data.now` + таймер (`setInterval` / `beforeUnmount`).
- Метод `isUrgent(quadrantId)` — срочный ли квадрант (по `urgency` из
  `getQuadrant`, либо по списку `['do','delegate']`).
- Методы-обёртки над `taskAge.ts`: уровень и подпись для задачи.
- Разметка: кружок-индикатор внутри `.task`, виден только когда квадрант
  срочный. Класс цвета по уровню. Кастомный тултип — вложенный
  `<span>` с `position: absolute`, показывается на `:hover`.
- CSS: цвета индикатора (зелёный/жёлтый/красный), стили тултипа.

## Тестирование

В проекте нет тест-раннера (ни Jest, ни Vitest, ни скрипта `test`). По
ограничению тулчейна TypeScript закреплён на 4.5 — добавление раннера сопряжено
с риском совместимости и выходит за рамки этой задачи.

Решение: вынести логику в чистый модуль `taskAge.ts`, чтобы её **можно было**
покрыть тестами позже, но сам раннер сейчас не ставить. Проверка результата —
ручная в браузере (`yarn serve`) и через `yarn lint`.

## Критерии готовности

- На карточках задач в `do` и `delegate` виден цветной кружок.
- Цвет соответствует возрасту по порогам 3ч / 8ч.
- При наведении на кружок виден кастомный тултип «висит N ч M мин».
- Цвет и текст обновляются со временем без перезагрузки (раз в минуту).
- Несрочные квадранты без индикатора.
- `yarn lint` проходит, `yarn build` собирается.
