## Язык общения

Всегда общаемся на русском языке. Все объяснения, комментарии в коде и
сообщения пользователю — на русском. Технические термины и идентификаторы
кода остаются в оригинальном виде.

## О проекте

Матрица Эйзенхауэра — мини-приложение для планирования личной нагрузки по
задачам. Стек: Vue 3 + TypeScript (Vue CLI), Vue Router, Vuex.

- Главный экран — матрица 4×4 (квадранты: Сделать / Запланировать /
  Делегировать / Удалить).
- Задачи создаются кликом по области, хранятся в `localStorage` в JSON.
- Запуск: `yarn serve`, сборка: `yarn build`, линт: `yarn lint`.
